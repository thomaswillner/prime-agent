## Environment learnings for the next session (this sandbox class)

- **Pin tools to the lock before validating.** `pip install -e ".[dev]"` pulls
  newer tools than CI: ruff 0.16.x flags rules 0.15.22 does not (892 KB of
  false findings on a clean tree). `pip install ruff==0.15.22` (from
  `requirements-py311-macos-arm64.lock`) restores parity.
- **`make secret-scan` false-positives here on the two fake Telegram fixtures**
  (`test_alert_channels.py:86`, `test_alerts_core.py:887`): their filtering
  relies on live token verification against api.telegram.org, which this
  proxied egress cannot complete. CI's own step is the gate of record.
- **PySide6 needs system Qt libs**: `apt-get update && apt-get install
  libegl1 libgl1 libxkbcommon0 libfontconfig1 libdbus-1-3 libglib2.0-0`,
  then the whole GUI lane runs offscreen.
- **The #58 alert-bridge flakes fire most runs here** and the conftest
  orchestration halts at the first failing partition — run the GUI files
  per-file afterwards to complete the lane, and finish `make coverage`
  manually (GUI `--cov-append` loop → `coverage json` → `coverage-guard`)
  when the flake kills the make target before the floor check.
- **Two environment-coupled deltas reproduce on the untouched tree** and are
  not signal: the #58 pair, and `test_gui_visual_overhaul`'s scroll-deficit
  ratchet (2545 px vs the 2526 px macOS golden — font metrics). CI (macos-26)
  is the environment of record for both.
- **Container clocks pause between turns**: `ps etime` measures resumed run
  time, not wall time — schedule waits with until-loop waiters on output
  files, not sleeps.
- `make preflight` degrades without `gh`; the equivalent collision check is
  the GitHub API (open PRs + branches + issues) before branching.
